## 用法（这段保留在文件末尾，不删）

**三条硬规则**

1. **只带指针 + 增量。** 给路径不给内容。重抄的那一刻起，它就和源文件开始漂移。
2. **写完贴回对话。** 落文件是给下一个 agent，贴回复是给此刻的用户。只写文件 = 用户不知道你留了什么。
3. **「下一步」必须是可执行的第一个动作。** 写"继续推进"等于没写；
   写"跑 `python tools/preflight.py` 看第 3 项是否还红"才算。

**与 AGENTS.md「已知坑」的分工**

| | 本文件（进展） | AGENTS.md「已知坑」 |
|---|---|---|
| 性质 | 过程，带日期带试错 | 结论：现象 + 触发条件 + 怎么绕 |
| 谁读 | 下一个 agent 进场第一件事 | 任何人干活前扫一眼 |
| 会不会删 | 不删，append 留全历史 | 定期蒸馏，只留结论 |

一次收尾写**两处**：坑的结论进 AGENTS.md（上了保险），这一棒的过程进本文件（保留"为什么"）。

**多任务线并行时**

两条线同时 append 会互相覆盖。按优先级：

1. **错峰写**：每条线只在自己这一棒结束时 append 一次，别边干边记。
2. **先读后写**：append 前先读回顶部两条，确认没把别人的挤掉。
3. **并行期分流**：并行期间各自写任务卡（`tasks/Txx-*.md`），只在汇合点写本文件。
   —— 任务卡是并行的，本文件是串行的。
